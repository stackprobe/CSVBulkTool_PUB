=============
CSV加工ツール
=============


----
説明

複数の CSV / TSV ファイルをまとめて加工する Windows 用のツールです。
ファイルを登録し、加工内容と出力先を選んで実行します。

主な機能

	・複数ファイルを1ファイルに結合する。
	・ファイルごとに加工して出力する。
	・セルの前後の空白、空行、重複行を削除する。
	・指定した列を文字列または数値として、昇順・降順に並べ替える。
	・ヘッダーの列名をそろえて結合する。
	・CSV / TSV、文字コード、改行コードを変換する。

最大 1000 件の入力ファイルを扱えます。
入力文字コードは Shift_JIS (CP932) と UTF-8 に対応しています。
出力は Shift_JIS (CP932)、UTF-8 (BOM あり・なし) を選択できます。

この Readme.txt は、アプリケーションの概要とインストーラの操作説明です。
加工機能の詳しい使い方は、インストール後の MainProgram.exe と同じフォルダにある
Readme.txt を参照してください。


----
動作環境

Windows / .NET Framework 4.8

インストール先に書き込みできる環境で使用してください。
アプリケーション本体も、実行ファイルと同じフォルダにログなどを作成します。


----
インストール

1. 配布された .zip をフォルダに展開する。
2. 展開したフォルダにある Installer.exe をダブルクリックする。
3. 画面の「インストール先」を確認する。
4. 必要に応じて「デスクトップにショートカットを作成する」を選択する。
5. 「インストール」を押す。
6. 確認画面の内容を確認し、「OK」を押す。
7. 完了画面で「OK」を押すと、インストーラが終了する。

※.zip 内のファイルは全て展開してください。
  Installer.exe だけを別のフォルダへ移動すると、インストールできません。
  同梱の MainProgram.cmp-gz と MainProgram.cmp-gz.hash が必要です。

※既存フォルダへのインストールや、同名ショートカットの作成では、
  上書き確認が表示される場合があります。内容を確認して選択してください。


----
インストール先

初期状態では、現在のユーザーの次のフォルダにインストールします。

	%LOCALAPPDATA%\CSVBulkTool

通常は次のような場所です。

	C:\Users\ユーザー名\AppData\Local\CSVBulkTool


参照...

	インストール先のフォルダを変更します。
	選択したフォルダが、そのままインストール先になります。
	本アプリケーション専用のフォルダを指定してください。

	ドライブのルートを選択した場合は、CSVBulkTool というフォルダ名を追加します。
	例えば C:\ を選ぶと、C:\CSVBulkTool になります。
	ネットワークパスは指定できません。


デフォルトに戻す

	インストール先を初期状態のフォルダに戻します。


インストール先のコピー

	インストール先欄を右クリックし、「コピー」を選ぶとパスをコピーできます。


※アンインストールでは、インストール先フォルダ全体を削除します。
  他のアプリケーションや必要なデータのあるフォルダは指定しないでください。


----
アプリケーションの起動

ショートカットを作成した場合

	デスクトップの「CSVBulkTool」をダブルクリックします。


ショートカットを作成しなかった場合

	インストール先の MainProgram フォルダにある MainProgram.exe を起動します。

	初期状態のインストール先の場合：

		%LOCALAPPDATA%\CSVBulkTool\MainProgram\MainProgram.exe


操作マニュアル

	MainProgram.exe と同じフォルダにある Readme.txt を開いてください。
	入力・加工・出力の設定、使用例、エラーやログの確認方法を記載しています。


基本操作

	1. 入力ファイルを画面の一覧へドラッグ＆ドロップする。
	2. 入力形式・文字コードと、必要な加工を選択する。
	3. 出力方法・形式・文字コード・改行コードを選択する。
	4. 「参照...」で出力先を指定し、「実行」を押す。

	※BOM なしの UTF-8 ファイルを読み込む場合は、
	  入力文字コードに「自動」ではなく「UTF-8」を選択してください。


----
再インストール・更新

1. CSV加工ツールを終了する。
2. 使用する配布ファイルを展開し、Installer.exe を起動する。
3. 「インストール先」に、現在インストールされているフォルダを指定する。
4. 「再インストール」を押し、確認画面で「OK」を押す。

インストール済みのフォルダを選ぶと、「インストール」が「再インストール」に変わります。
インストール先を変更していた場合は、「参照...」からそのフォルダを選んでください。
指定するのは MainProgram フォルダではなく、その親のインストール先フォルダです。

再インストールでは、配布物に含まれる同名のファイルを上書きします。
必要なファイルを変更・保存している場合は、事前に別の場所へコピーしてください。


----
アンインストール

1. CSV加工ツールを終了する。
2. インストール先に保存した必要なデータを、別のフォルダへ退避する。
3. Installer.exe を起動する。
4. 「インストール先」に、削除したいインストール先フォルダを指定する。
5. 表示された「アンインストール」を押す。
6. ショートカットの削除確認が表示されたら、「はい」または「いいえ」を選択する。
7. 削除対象を確認し、アンインストール実行の確認で「OK」を押す。
8. 完了画面で「OK」を押すと、インストーラが終了する。

※インストール先フォルダにある全てのファイルとサブフォルダを削除します。
  自分で保存した CSV / TSV やログなども削除対象です。
  必要なデータは必ずインストール先の外へ退避してください。

※「キャンセル」を選ぶと、アンインストールを中止します。
※ショートカット削除の確認で「いいえ」を選んだ場合、ショートカットは残ります。

再インストール・アンインストールに使用するため、配布された .zip を保管してください。


----
エラーが表示された場合

インストール先のフォルダは現在使用されています。

	CSV加工ツールを終了してください。
	インストール先を開いている他のソフトウェアも閉じて、再度実行してください。


クラスタファイル、またはハッシュ値が見つからない。

	.zip を全て展開したか確認してください。
	Installer.exe と同じフォルダに、次のファイルが必要です。

		MainProgram.cmp-gz
		MainProgram.cmp-gz.hash


クラスタファイルが破損している。

	配布された .zip を再取得し、別のフォルダへ展開して実行してください。


書き込みやアクセスに関するエラー

	インストール先に書き込みできるか確認してください。
	他のソフトウェアが対象ファイルを使用していないかも確認してください。


エラー画面の「詳細を表示する」から、詳しい内容を確認できます。
