=============
CSV加工ツール
=============


----
説明

複数の CSV / TSV ファイルをまとめて加工するツールです。
空白・空行・重複行の削除、並べ替え、文字コードやファイル形式の変換ができます。
加工した結果は、1ファイルに結合するか、ファイルごとに出力します。


----
動作環境

Windows / .NET Framework 4.8

MainProgram.exe と同じフォルダにログなどを作成します。
このフォルダに書き込みできる状態で使用してください。


----
起動・終了

MainProgram.exe をダブルクリックして起動します。
画面右上の「×」で終了します。


----
基本的な使い方

1. 「1. 入力」に加工するファイルを追加する。
2. 入力形式と文字コードを選択する。
3. 「2. 加工」で必要な加工にチェックを入れる。
4. 「3. 出力」で出力方法・形式・文字コード・改行コードを選択する。
5. 「参照...」で出力先を指定する。
6. 「実行」を押す。

既存のファイルを上書きする場合は確認画面が表示されます。
入力の検査でエラーが見つかった場合は、出力せずにエラー一覧を表示します。


----
入力

入力ファイル一覧

	ファイルを一覧へドラッグ＆ドロップするか、「追加」で選択します。
	CSV / TSV ファイルを最大 1000 件まで追加できます。

	「削除」   ... 選択したファイルを一覧から取り除く。
	「全削除」 ... 一覧を空にする。
	「上へ」   ... 選択したファイルを1つ上へ移動する。
	「下へ」   ... 選択したファイルを1つ下へ移動する。

	※一覧から取り除いても、元のファイルは削除しません。
	※同じファイルを重複して追加すると、実行時の検査でエラーになります。


入力形式

	拡張子から判定   ... .csv を CSV、.tsv を TSV として読み込む。
	全て CSV と見なす ... 拡張子に関係なく CSV として読み込む。
	全て TSV と見なす ... 拡張子に関係なく TSV として読み込む。

	.txt などのファイルを扱う場合は、追加前に
	「全て CSV と見なす」または「全て TSV と見なす」を選択してください。


文字コード

	自動                ... UTF-8 の BOM があれば UTF-8、それ以外は CP932。
	Shift_JIS (CP-932)   ... CP932 として読み込む。
	UTF-8               ... UTF-8 として読み込む。BOM の有無はどちらでも可。

	※BOM はファイルの先頭に付く、文字コードを示す印です。
	※BOM なしの UTF-8 ファイルは「UTF-8」を選択してください。
	※「自動」はファイルの内容から文字コードを推測する機能ではありません。


入力形式・文字コードの設定は、一覧の全ファイルに適用されます。


----
加工

先頭行をヘッダ行と見なす

	各ファイルの先頭行を列名として扱います。
	ヘッダー行は空行削除・重複削除・ソートの対象に含めません。
	チェックを外すと、先頭行からデータとして扱います。

	ヘッダーありで結合する場合、同じ列名のデータを同じ列にそろえます。
	列の並びは最初のファイルを基準とし、後続ファイルにだけある列は末尾に追加します。
	入力ファイルに存在しない列は空欄になります。
	ヘッダーは結合結果の先頭に1回だけ出力します。

	※空の列名、重複する列名、制御文字を含む列名は使用できません。
	※列名の大文字・小文字は区別します。
	※ヘッダーなしの場合は、列名による対応付けを行いません。


全てのセルの前後空白を削除する

	セルの先頭・末尾の空白を削除します。ヘッダーの列名にも適用します。
	セルの途中にある空白は削除しません。


空行削除

	全てのセルが空の行を削除します。
	空白だけのセルも空と見なす場合は、前後空白の削除も選択してください。


重複行を削除

	全ての列の値が一致する行を1行にまとめます。
	大文字・小文字は区別します。


ソートする

	指定した1列を基準に並べ替えます。

	列         ... ヘッダーの列名、または「1 列目」などから選択する。
	データ型   ... 文字列 / 数値
	ソート順   ... 昇順 / 降順

	文字列は文字コードの順に比較します。
	数値は数の大きさで比較します。例えば昇順では 2、10、100 の順になります。

	数値の小数点には半角の . を使用してください。
	桁区切りのカンマや通貨記号など、数値として扱えない値があるとエラーになります。
	空欄は、昇順では数値より前、降順では数値より後に並びます。


前後空白の削除、空行削除、列の対応付け、重複削除、ソートの順に加工します。
重複削除とソートは、結合出力では結合後の全データ、個別出力では各ファイルが対象です。
ソートしない場合は、入力一覧の順番と各ファイル内の行順で処理します。


----
出力

出力方法

	1ファイルに結合

		全入力の加工結果を、指定した1つのファイルに出力します。
		「参照...」で出力ファイルを指定してください。

	ファイルごとに出力

		入力ファイルごとに加工し、指定したフォルダへ出力します。
		「参照...」で出力フォルダを指定してください。
		出力名は、入力ファイルの拡張子を .csv または .tsv に変えた名前です。

		例：売上.txt を TSV で出力すると 売上.tsv になります。

		※出力ファイル名が重複する場合はエラーになります。


出力形式

	自動 (入力に合わせる) ... 結合時は最初の入力、個別出力時は各入力の形式に合わせる。
	CSV                    ... カンマ区切りで出力する。
	TSV                    ... タブ区切りで出力する。

	※結合時の出力ファイル名は、指定した名前をそのまま使います。
	  拡張子も出力形式に合わせて指定してください。


文字コード

	Shift_JIS (CP-932)
	UTF-8 (BOM あり)
	UTF-8 (BOM なし)

	※CP932 で表現できない文字がある場合はエラーになります。
	  その場合は、出力文字コードを UTF-8 に変更してください。


改行コード

	CR-LF ... Windows で一般的な改行。
	LF    ... LF のみの改行。

	出力先のソフトウェアで指定されている場合は、それに合わせてください。
	この設定は行の区切りに適用されます。セル内の改行は元のままです。


出力先のドラッグ＆ドロップ

	出力先欄に既存のファイルをドロップすると「1ファイルに結合」、
	フォルダをドロップすると「ファイルごとに出力」に切り替わります。

	※出力方法を切り替えると出力先欄が空になります。出力先を改めて指定してください。
	※入力ファイルと同じ場所・名前を指定すると、入力ファイルを上書きします。


----
使用例

複数の売上 CSV を結合し、金額順に並べる場合

	1. 売上 CSV を入力一覧に追加する。
	2. 入力文字コードをファイルに合わせて選択する。
	3. 「先頭行をヘッダ行と見なす」にチェックを入れる。
	4. 「ソートする」にチェックを入れる。
	5. 列に金額の列名、データ型に「数値」、ソート順に「降順」を選択する。
	6. 出力方法に「1ファイルに結合」、出力形式に「CSV」を選択する。
	7. 出力文字コード・改行コードを選択する。
	8. 「参照...」で結合結果のファイルを指定して「実行」を押す。


複数の CSV を、個別に BOM なし UTF-8 の TSV へ変換する場合

	1. CSV を入力一覧に追加する。
	2. 入力文字コードをファイルに合わせて選択する。
	3. 先頭行が列名でなければ「先頭行をヘッダ行と見なす」のチェックを外す。
	4. 空白削除・空行削除・重複削除・ソートのチェックを外す。
	5. 出力方法に「ファイルごとに出力」、出力形式に「TSV」を選択する。
	6. 出力文字コードに「UTF-8 (BOM なし)」を選択する。
	7. 改行コードを選択する。
	8. 「参照...」で出力フォルダを指定して「実行」を押す。


----
エラー・ログ

入力の検査でエラーが見つかった場合は、出力せずにエラー一覧を表示します。
表示されたファイルや設定を修正し、再度実行してください。

主な確認事項

	文字が正しく読み込めない ... 入力文字コードを確認する。
	引用符のエラー           ... セルを囲む " が閉じられているか確認する。
	ヘッダーのエラー         ... 空の列名・重複する列名・制御文字を確認する。
	数値ソートのエラー       ... 対象列の文字、桁区切り、通貨記号などを確認する。
	出力ファイル名の重複     ... 同じ出力名になる入力ファイルを確認する。
	出力できない             ... 出力先の書き込み権限や、他のソフトで開いていないか確認する。

MainProgram.exe と同じフォルダに、次のログを作成します。

	MainProgram.exe.log       ... 処理の開始・完了、出力先、出力行数など。
	MainProgram.exe.error.log ... エラー内容。

※ログは実行のたびに上書きされます。
※ログの文字コードは UTF-8 (BOM あり) です。


----
補足

CSV / TSV の引用符で囲まれたセル、セル内の区切り文字・改行に対応しています。
セル内の " は、引用符で囲んだセルの中で "" と記述します。

通常のセルでは CR・LF・TAB 以外の制御文字は使用できません。
ヘッダーでは全ての制御文字が使用できません。
ヘッダーより列数が多いデータはエラーになり、不足する列は空欄になります。

処理中は入力ファイルを変更しないでください。
ソートや重複削除ではデータ量に応じてメモリを使用します。
大量のデータを扱う場合は、入力ファイル数やデータ量を減らして実行してください。

出力は一時ファイルに書き込んでから確定します。
出力の確定途中で失敗した場合は、確定済みの出力を元に戻す処理を行います。
復元にも失敗した場合は、エラーに表示される出力先とバックアップを確認してください。
